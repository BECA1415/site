1. Componentes de Computadores

1.1 Componentes Internos

1.1.1 CPU

A CPU (Central Processing Unit) é o cérebro do computador, responsável por executar instruções e processar dados.

1.1.2 Armazenamento

O armazenamento é onde os dados e sistemas operacionais são guardados, podendo ser HDDs ou SSDs.

1.1.3 Memória

A memória RAM (Random Access Memory) é usada para armazenar dados temporários durante a execução de programas.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte energia elétrica da rede para alimentar os componentes internos do computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é o principal dispositivo de entrada, usado para digitar texto e comandos no computador.

1.2.2 Monitor de vídeo

O monitor exibe informações gráficas e visuais geradas pelo computador.

1.2.3 Mouse

O mouse é um dispositivo apontador usado para controlar o cursor na tela.

1.3 Interfaces de Entrada e Saída

1.3.1 Interfaces sem fio

Interfaces sem fio incluem tecnologias como Wi-Fi e Bluetooth para comunicação sem cabos.

1.3.2 Áudio

As interfaces de áudio conectam dispositivos de entrada e saída de som, como microfones e alto-falantes.

2. Grandezas Elétricas

2.1 Potência Elétrica

A potência elétrica é a taxa de consumo de energia por um dispositivo elétrico.

2.2 Tensão Elétrica

A tensão elétrica, também conhecida como diferença de potencial, é a força que move a corrente elétrica em um circuito.

2.3 Corrente Elétrica

A corrente elétrica é o fluxo de cargas elétricas em um condutor.
